X 评论聊天翻译 v1.0.0（原名 Grok 输入框翻译）

从 Chrome 应用商店安装的用户不需要看这份说明；以下是手动加载解压包的步骤。

1. 将安装 ZIP 解压到固定目录（不要把 ZIP 直接拖进扩展页，那样之后无法覆盖升级）。
2. 打开 chrome://extensions 或 edge://extensions，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择直接包含 manifest.json 的解压目录。
4. 点击插件图标，打开连接设置，点击“连接 Grok”。
5. 核对短码，前往 xAI 官方页面亲自完成授权。页面可能显示共享客户端 Grok Build。
6. 回到设置页确认已连接及模型。默认选用不先推理、速度更快的 grok-4.20-0309-non-reasoning（标“推荐”），没有时依次改用其他带 non-reasoning 的模型或 grok-4.3；都没有时请手动选择。
7. 刷新 X 页面，在帖子详情页的行内回复框，或时间线点“回复”打开的弹窗中输入中文，点击“译成英文”。

成功后英文填回原框，下方保留中英文对照。翻译期间有新编辑时只展示译文，不覆盖新草稿。
“恢复中文”仅在英文未再编辑时可用；也可复制原文。发布由你自行点击 X 的回复按钮。

默认勾选“在本机记住登录”：登录加密保存在本机，重启浏览器后不用重新授权；取消勾选则只保留本次浏览器会话。
登录每隔几小时自动续期；电脑刚唤醒、网络还没连上时续期失败，插件会保留登录并自动重试，不需要重新授权。
X 聊天（私信）输入框也可翻译，但默认关闭：私信可能更私密，需要时在设置的「X 聊天翻译」中勾选“在 X 聊天中启用翻译”，随时可关闭。开启后只在你点击时发送当前聊天草稿，不读取聊天记录或对方消息。
当前不支持普通发帖、引用发帖、其他网站或英文译中文。单次最多 8,000 个 Unicode 字符。

从旧版升级：
- 在扩展管理页移除旧的“Grok 输入框翻译”，只保留一个副本（从 ZIP 拖入安装的旧副本位于 User Data\Default\UnpackedExtensions，必须移除）。
- 加载本目录后确认版本显示 1.0.0 并已启用；换了目录需要在设置中重新连接 Grok。
- 以后从同一目录升级：覆盖文件后点击该扩展的“重新加载”，再刷新 X 页面。
- 在 X 页面控制台执行 document.querySelector('grok-input-panel')?.dataset.version，应显示 1.0.0。

普通 X/Grok 订阅不一定具备所需 API 权限；额度、模型、费用以账号和 xAI 实际结果为准。
