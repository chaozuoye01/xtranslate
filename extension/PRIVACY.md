# 隐私说明

X 评论聊天翻译 v1.0.0，2026-11-10。公开网址：https://zuoye.si/xtranslate/privacy/

只有点击“译成英文”后，插件才读取对应评论输入框（或已开启时的 X 聊天输入框）的草稿，并由扩展后台直接发送到 `https://api.x.ai/v1/responses`。请求包含草稿、翻译指令和已选模型，并设置 `store:false`。这一设置控制接口的会话保存选项，不等于服务商不存在其他运营或合规保留；实际数据处理以 xAI 规则为准。

不读取原帖正文、其他评论、浏览历史、Cookie 或密码；不调用搜索工具，不设中转服务器。页面适配会读取编辑器属性、回复按钮、X 回复弹窗历史状态中的回复对象编号，以及帖子链接、作者和时间，仅用于在页面内定位正确输入框，这些信息不发送出去。

**X 聊天（私信）翻译默认关闭。** 只有在插件设置中主动勾选“在 X 聊天中启用翻译”后，插件才会查找 X 聊天页面的输入框并显示按钮；关闭时不读取、不监听聊天页面。开启后，点击翻译时只发送当前聊天输入框里的这段草稿，不读取聊天记录、对方消息、联系人或会话列表。页面地址中的会话编号只用于在页面内防止把译文填进另一个会话，不发送出去。私信可能比公开回复更敏感，请自行判断是否开启。随时可关闭，关闭后进行中的聊天翻译会被取消，按钮立即移除。这个开关只能在插件自己的设置页修改，网页无法替你打开。

中文原文及英文译文只保留在当前页面内存，便于对照、复制和恢复。关闭页面或退出/更换登录时清除本插件的页面结果；不建立草稿历史，不使用浏览器同步。填入 X 输入框后的内容属于 X 页面草稿，其后续保存由 X 管理。

Grok 登录使用参考 SuperX 的公开设备码 OAuth 客户端。官方授权页面可能显示 Grok Build，而非本插件名称。本插件不是 xAI 官方产品。请求范围为 `openid offline_access grok-cli:access api:access`，不主动请求姓名或邮箱。

Access Token 仅在受限浏览器会话存储和后台内存中使用，网页和内容脚本不能访问。“在本机记住登录”默认勾选：Refresh Token 由不可导出的本机 AES-GCM 密钥加密保存，密钥保存在扩展 IndexedDB，重启浏览器后不用重新授权。取消勾选则只在本次浏览器会话中保留登录，关闭浏览器即失效。单独泄露的密文不含明文凭据，但加密不能保护已被控制的电脑或整个浏览器配置。退出登录会删除插件登录凭据并尽力向服务商撤销 Refresh Token。

登录凭据每隔几小时自动续期。续期时如果连不上 xAI 或 xAI 返回临时错误，插件保留登录，稍后自动重试（30 秒、1 分钟、2 分钟、5 分钟，之后每 15 分钟），点击翻译时也会立即重试；只有 xAI 明确拒绝时才需要重新连接。最近一次续期失败的时间、类型（网络、HTTP 状态码和 OAuth 错误码）和次数保存在本机，显示在设置页，不含凭据，也不发送出去。

设置只保存模型选择、记住登录偏好、X 聊天翻译开关、上述登录状态和最近一次续期失败的记录。翻译错误不展示服务商原始响应或凭据。剪贴板只在点击复制按钮时写入选定的原文或译文，不读取剪贴板。填入输入框通过页面内模拟的粘贴事件完成，不经过也不改动系统剪贴板。

所需权限：`storage` 保存设置与登录；`alarms` 维持授权轮询及过期刷新；站点范围仅 X、Twitter、xAI 官方授权及 API 域名。插件不自动发布评论，也不自动发送聊天消息。用量、费用和模型权限取决于账号实际资格。

本地演示使用模拟登录及固定译文，不读取真实凭据、不调用 Grok，也不发送评论。
